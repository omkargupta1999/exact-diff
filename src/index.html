MouseClick a line to select it and see it in the line details pane. Double-click to edit it. Right-click for copy options. Click the arrow at the start of a section to copy it across. Click a fold bar to expand it.
Changed (≠): the same logical line differs. Light = changed word, strong = exact characters. Removed (−): the line exists only on the left. Added (+): the line exists only on the right. Unimportant (≈): differs only in text the current rules ignore. Not counted as a difference. No counterpart line on this side. Unusual space such as a no-break space. Invisible and bidi control characters show as a red badge.

Strict compares the exact characters of each line plus its line ending: spaces, tabs, case, punctuation, Unicode (never normalised), blank lines, CR / LF / CRLF and a missing final newline all count. A file ending in a newline has no extra empty last line, as in most diff tools.

Saving keeps each line's original line ending and the file's encoding. In Chrome and Edge a file opened with Open is written back in place after the browser asks for permission; elsewhere it downloads.

Privacy. The page's Content-Security-Policy forbids every network request. Files are read with the File API; nothing is uploaded or stored. Only settings go to localStorage.
