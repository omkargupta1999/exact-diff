## [1.0.0] - 2026-10-07

### Added
- Character-exact, side-by-side comparison with line, word and character highlighting.
- Strict mode by default; rules to ignore whitespace, case, blank lines, line endings or a regular expression.
- Patience + Myers, Myers O(ND) and line-by-line algorithms; diffing in a background worker.
- Navigation (F7/F8), overview map, All / Diffs / Context / Same filters, line details pane.
- Copy sections left/right, swap, undo/redo, find and replace with regular expressions, Edit view.
- Open, drag and drop, paste and save with original encoding (UTF-8, UTF-8 BOM, UTF-16) and line endings.
- HTML report export and plain-text diff summary.
- Light and dark themes, stacked layout, resizable panes, word wrap.
- Installable offline web app (PWA) and Electron desktop packages for Windows, Linux and macOS.
- CI with unit and cross-browser end-to-end tests, CodeQL, Dependabot and release provenance.
